# New UI Implementation Plan (piece 1 of 3)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-extended-cc:subagent-driven-development (recommended) or superpowers-extended-cc:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A modern responsive UI (desktop, phone, TV) in the "big header" style with covers: Home with rows of posters, cover-grid Search, a Title page with hero, language chips and episode tiles, and the player restyled, with the five title-action buttons drawn (not wired).

**Architecture:** A token-based stylesheet (`theme.css`) plus small Svelte components in `src/lib/ui/` (Cover, Poster, PosterRow, PosterGrid, Hero, Shell, EpisodePicker). Screens `Home` and `Title` are new; `Search` and `Player` are restyled; `App.svelte` is restructured around a `Shell`. One new Rust command (`get_list`) feeds the Home rows by reusing the search-table parser. A dev-only demo mode (fake data, no login) lets agents screenshot every screen with headless Chrome.

**Tech Stack:** Svelte 5 + TypeScript + Vite, `node --test` for pure TS, Rust (existing crates), headless `google-chrome-stable` for screenshots.

**Spec:** `docs/superpowers/specs/2026-10-20-new-ui-design.md`

## Global Constraints

- Keep everything that already works: login and saved credentials, search with paging, episode paging, both stream types, the player (retry, fullscreen, guarded iframe), spatial D-pad navigation, Back stack, TV mode, IME lock, player focus scope. The 50 Rust tests and 12 web tests stay green; `npm run check` stays at 0 errors and 0 warnings; the CSP is unchanged (images come from `https:` only).
- No new dependencies, no CSS framework. Dark theme only.
- Every interactive element is a real `<button>`, `<input>` or `<a>` (spatial navigation finds them); focus ring comes from the `--ring` token. Rows/grids must not trap focus.
- Cover URL is `https://cdn.proxer.me/cover/<id>.jpg`, built in the browser from the title id. Images use `loading="lazy"` and a placeholder on error.
- Rows with no hits hide themselves (Proxer's "Most viewed" list is empty right now and will be refilled later). A failed row shows the existing `describeError` text plus a Retry button; `NotLoggedIn` goes to Login.
- Never log tokens, URLs with tokens or credentials. The dev-only demo mode must not exist in production bundles (guarded by `import.meta.env.DEV` and the absence of `window.__TAURI_INTERNALS__`).
- Deviations from the spec, deliberate: `get_list(kind)` has no page argument (Home needs page 1 only; `ponytail:` add paging if a "see all" screen appears); episode pages are shown as a row of chips next to the language chips (not a dropdown), which is more remote-friendly and is on the left as requested; the hero meta line uses the info-page fields available (Status, Genre), not a rating.
- Out of scope: working action buttons (piece 2), Calendar (piece 3), Library tab, light theme.

**User decisions (already made):** layout C (big header) with covers; Home = rows of covers (Airing now, Top rated, Most viewed; empty rows hide); page switch on the left; one layout for desktop and TV; build order new look, then actions, then calendar.

```rust
/// Home rows: kind -> the Proxer list page (same `tr.entry` table as search).
fn list_path(kind: &str) -> Option<&'static str> {
    match kind {
        "airing" => Some("/anime/airing"),
        "rating" => Some("/anime/animeseries/rating/all"),
        "clicks" => Some("/anime/animeseries/clicks/all"),
        _ => None,
    }
}

#[tauri::command]
pub async fn get_list(app: State<'_, App>, kind: String) -> Result<SearchPage, String> {
    let path = list_path(&kind).ok_or_else(|| "Unsupported".to_string())?;
    let html = app.client.get(path).await.map_err(err)?;
    Ok(parse_search_page(&html))
}
```

```ts
import type { Episode } from "../api.ts";

/** Cover image for a title id; built in the browser, no parsing needed. */
export const coverUrl = (id: number) => `https://cdn.proxer.me/cover/${id}.jpg`;

const ORDER = ["engsub", "engdub", "gersub", "gerdub"];

export function languagesOf(episodes: Episode[]): string[] {
  const all = [...new Set(episodes.flatMap((e) => e.langs))];
  const rank = (l: string) => (ORDER.includes(l) ? ORDER.indexOf(l) : ORDER.length);
  return all.sort((a, b) => rank(a) - rank(b) || a.localeCompare(b));
}

export function episodesWith(episodes: Episode[], lang: string): number[] {
  return episodes.filter((e) => e.langs.includes(lang)).map((e) => e.number).sort((a, b) => a - b);
}
```

```svelte
<script lang="ts">
  import { onMount } from "svelte";
  import { api, describeError, streamLabel, type Episode, type Info, type PageLink, type Stream } from "./api";
  import { pushBack } from "./back";
  import Player from "./Player.svelte";
  import Hero from "./ui/Hero.svelte";
  import EpisodePicker from "./ui/EpisodePicker.svelte";
  import { languagesOf } from "./ui/helpers";
  let { id, onback, onauth }: { id: number; onback: () => void; onauth: () => void } = $props();
  let info = $state<Info | null>(null), episodes = $state<Episode[]>([]), pages = $state<PageLink[]>([]);
  let epPage = $state(1), streams = $state<Stream[]>([]), lang = $state(""), playing = $state<Stream | null>(null);
  let selected = $state<{ ep: number; lang: string } | null>(null), error = $state("");
  onMount(() => pushBack(() => { onback(); return true; }));
  function fail(x: unknown) { if (x === "NotLoggedIn") onauth(); else error = describeError(x); }
  async function loadPage(p: number) {
    const cur = id;
    try {
      const l = await api.episodes(cur, p);
      if (cur !== id) return;
      episodes = l.episodes; epPage = p;
      if (l.pages.length) pages = l.pages;
      error = "";
    } catch (x) { fail(x); }
  }
  $effect(() => {
    const cur = id;
    (async () => {
      try { const i = await api.info(cur); if (cur === id) info = i; } catch (x) { fail(x); return; }
      await loadPage(1);
    })();
  });
  async function pick(ep: number, l: string) {
    selected = { ep, lang: l }; streams = []; playing = null; error = "";
    const mine = selected; // drop the result if another pick happened meanwhile
    try {
      const r = await api.streams(id, ep, l);
      if (selected === mine) streams = r;
    } catch (x) { if (selected === mine && x !== "Parse:streams") fail(x); }
  }
  /** Play the first supported stream of the first episode in the chosen (or first available) language. */
  async function watch() {
    const l = lang || languagesOf(episodes)[0];
    const first = episodes.find((e) => e.langs.includes(l));
    if (!first) return;
    await pick(first.number, l);
    const s = streams.find((x) => streamLabel(x) !== "Unsupported");
    if (s) playing = s;
  }
  const meta = $derived([info?.fields["Status"], info?.fields["Genre"]].filter(Boolean).join(" · "));
</script>
```
